# Shakespeare_example

The data to train for the shakespeare task can be downloaded here or use wget https://raw.githubusercontent.com/karpathy/char-rnn/master/data/tinyshakespeare/input.txt. Place the downloaded 'input.txt' file in the same folder as the python scripts to train the models. An example model can be trained by running the Shakespeare_MHSA_model.py, which saves the best trained model, with generation of some illustrative texts.
